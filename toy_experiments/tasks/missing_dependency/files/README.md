# reportd

Small reporting service.

- Start:        /opt/reportd/bin/reportd start
- App code:     /opt/reportd/app/server.py
- Requirements: /opt/reportd/requirements.lock
- Vendor dir:   /opt/reportd/vendor
- Logs:         /var/log/reportd/
- Data:         /var/lib/reportd/

On a successful start the launcher prints `reportd: started (pid N)` and exits 0.
